# Telegram бот-калькулятор Kaspi

Нужен Node.js 18 или новее. Создайте бота через @BotFather и сохраните токен как переменную среды `TELEGRAM_BOT_TOKEN`.

В PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN = 'НОВЫЙ_ТОКЕН_ОТ_BOTFATHER'
node .\bot.js
```

Чтобы открыть визуальный калькулятор прямо в Telegram, сначала разместите `index.html` на HTTPS-хостинге (например, GitHub Pages). Затем задайте его адрес в `WEB_APP_URL`:

```powershell
$env:WEB_APP_URL = 'https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/'
node .\bot.js
```

Окно PowerShell должно оставаться открытым, пока бот работает. В Telegram откройте бота и отправьте `/start`, затем нажмите «Открыть калькулятор». Если `WEB_APP_URL` не задан, работает обычный текстовый режим бота.

Визуальная страница запрашивает количество, себестоимость одной штуки, вашу доставку за одну штуку и цену продажи; пересчёт идёт сразу. Доставку за штуку страница умножает на количество. Комиссия Kaspi QR 0,95%, налог 4% и тарифы Kaspi перенесены из приложенной таблицы. Тариф доставки Kaspi учитывается на каждую единицу товара.
